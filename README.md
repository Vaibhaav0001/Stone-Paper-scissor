✊🖐✌️ Stone Paper Scissors Game (Rock Paper Scissors)
A fun and interactive Stone Paper Scissors game (also known as Rock Paper Scissors) built using HTML, CSS, and JavaScript. In this game, you play against the computer. The result is displayed after each round, and your total wins, losses, and draws are tracked as you play!

🎮 Features
🤖 Play against a computer opponent

📈 Keeps track of:

Number of times you win

Number of times computer wins

Number of draws

🥳 Shows message at the end of each round:

"You Win!"

"You Lost!"

"Game was Draw. Play again!"

🔁 Option to play continuously without refreshing

💻 Responsive and clean design

🛠️ Technologies Used
HTML – Structure of the webpage

CSS – Styling and layout

JavaScript – Game logic and interactivity

🚀 How to Play
Choose between Stone, Paper, or Scissors.

The computer randomly picks its move.

The result is displayed with a message and the score is updated.

Keep playing as much as you like!

📂 Setup Instructions
Clone the repository:https://github.com/Vaibhaav0001/Stone-Paper-scissor

Open the index.html file in your browser and enjoy the game!
